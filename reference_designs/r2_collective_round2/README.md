# Round 2 collective (reference only)

The deliverable the round 2 arm handed in: a leaderless six-agent collective, designed against the goal metric of addendum 4 (`sim/EVAL_SPEC_v1.md` addenda). It is a 30.3 x 20.3 x 12.5 mm Tough 1500 channel lattice, solid fraction 0.41.

Files: `implant.stl`, `implant.form`, `material_spec.json`, `report.md`.

Independent full-resolution scores are in [`../../RESULTS.md`](../../RESULTS.md); the agents' own coarse-tool value in `report.md` differs from them.

`report.md` gives evidence paths such as `kb/...` relative to the arm folder (the shared knowledge base). That folder is not shipped.
